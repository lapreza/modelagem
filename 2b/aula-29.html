Semana 8 — Aula 1

Introdução às Cláusulas SELECT

O Comando SELECT em SQL

O comando SELECT é a instrução mais fundamental da Linguagem DQL (Data Query Language). Ele é utilizado para consultar e extrair registros de uma ou mais tabelas armazenadas no Sistema Gerenciador de Banco de Dados (SGBD).

Sintaxe Básica:

SELECT coluna1, coluna2, ...
FROM nome_da_tabela;

1. Seleção de Colunas e Aliases (`AS`)

Podemos selecionar colunas específicas ou usar o caractere coringa (*) para retornar todas as colunas disponíveis na tabela. O uso de Aliases (AS) renomeia temporariamente os cabeçalhos das colunas nos resultados exibidos. 

-- Selecionando todas as colunas da tabela de Alunos
SELECT * FROM alunos;

-- Selecionando colunas específicas com Aliases
SELECT nome_aluno AS "Nome do Estudante", email AS "E-mail de Contato"
FROM alunos;

2. Filtragem de Dados com a Cláusula `WHERE`

A cláusula WHERE restringe as linhas retornadas pela consulta, aplicando condições lógicas e relacionais (=, <>, >, <, BETWEEN, IN, LIKE). 

-- Filtrando alunos cadastrados em um curso específico
SELECT nome_aluno, curso 
FROM alunos 
WHERE curso = 'Informática';

-- Filtrando por padrão de texto usando LIKE (Alunos com nome iniciando em 'A')
SELECT nome_aluno, email 
FROM alunos 
WHERE nome_aluno LIKE 'A%';

3. Ordenação (`ORDER BY`) e Limitação (`LIMIT`)

Para organizar os dados retornados, utiliza-se a cláusula ORDER BY (definindo ordem ascendente ASC ou descendente DESC). A cláusula LIMIT restringe a quantidade máxima de registros retornados. 

-- Ordenando alunos por nome em ordem alfabética e limitando aos 5 primeiros
SELECT nome_aluno, data_nascimento 
FROM alunos 
WHERE curso = 'Informática'
ORDER BY nome_aluno ASC 
LIMIT 5;

Boas Práticas de Desempenho: Evite o uso indiscriminado de SELECT * em ambientes de produção. Sempre especifique apenas as colunas necessárias para economizar tráfego de rede e consumo de memória RAM do servidor.

Semana 8 — Aula 2

Funções de Agregação em SQL

O que são Funções de Agregação?

As Funções de Agregação processam um conjunto de valores em uma coluna de uma tabela e retornam um único valor resumido. São ferramentas indispensáveis para a geração de relatórios estatísticos e análise de dados operacionais.

1. As 5 Funções de Agregação Principais

  • COUNT(): Retorna o número total de linhas ou de valores não nulos.
  • SUM(): Calcula a soma total de valores numéricos de uma coluna.
  • AVG(): Retorna a média aritmética dos valores de uma coluna.
  • MIN(): Encontra o menor valor registrado numa coluna.
  • MAX(): Encontra o maior valor registrado numa coluna.
-- Exemplos de uso direto de funções de agregação
SELECT 
    COUNT(*) AS total_alunos,
    AVG(nota_final) AS media_geral,
    MIN(nota_final) AS menor_nota,
    MAX(nota_final) AS maior_nota
FROM matriculas;

2. Agrupamento de Dados com `GROUP BY`

A cláusula GROUP BY divide os registros da tabela em grupos com base em um ou mais atributos comuns. Quando combinada com funções de agregação, permite calcular resumos estatísticos para cada subgrupo individualmente. 

-- Calculando a quantidade de alunos e a média de idade por curso
SELECT curso, COUNT(*) AS qtd_alunos, AVG(idade) AS media_idade
FROM alunos
GROUP BY curso;

Regra de Ouro do `GROUP BY`: Todas as colunas presentes na lista do SELECT que não façam parte de uma função de agregação devem obrigatoriamente constar na cláusula GROUP BY.

3. Tratamento de Valores Nulos (NULL)

As funções de agregação como SUM() e AVG() ignoram automaticamente valores NULL nas colunas processadas. Para contagem total de registros incluindo linhas nulas, utiliza-se COUNT(*). 

-- Conta apenas os alunos com e-mail cadastrado (ignora NULLs)
SELECT COUNT(email) FROM alunos;

-- Conta todas as linhas existentes na tabela
SELECT COUNT(*) FROM alunos;

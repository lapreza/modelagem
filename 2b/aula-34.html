Semana 9 — Aula 2

A Cláusula HAVING em SQL

Filtrando Grupos de Dados

A cláusula HAVING foi introduzida na linguagem SQL especificamente para aplicar condições de filtro em **dados agregados**, uma vez que a cláusula WHERE não pode ser utilizada com funções de agregação (como SUM(), AVG(), COUNT()).

1. Diferença entre WHERE e HAVING

WHERE: Filtra **linhas individuais** antes do agrupamento dos dados (GROUP BY).

HAVING: Filtra **grupos de linhas** depois que o agrupamento e as funções de agregação foram calculados.

-- Exemplo combinando WHERE e HAVING
SELECT curso, COUNT(*) AS qtd_alunos, AVG(nota_final) AS media_curso
FROM matriculas
WHERE situacao = 'Concluído'  -- Filtra linhas individuais antes de agrupar
GROUP BY curso
HAVING AVG(nota_final) >= 7.0; -- Filtra apenas os grupos cuja média final seja >= 7.0

2. Ordem Lógica de Execução do SELECT

Compreender a ordem em que o SGBD processa cada cláusula da consulta é fundamental para evitar erros de sintaxe:

  1. FROM: Identifica e carrega as tabelas de origem.
  2. JOIN: Une as tabelas relacionáveis.
  3. WHERE: Filtra as linhas individuais.
  4. GROUP BY: Agrupa as linhas filtradas.
  5. HAVING: Filtra os grupos resultantes.
  6. SELECT: Projeta as colunas e executa aliases.
  7. ORDER BY: Ordena o resultado final.
  8. LIMIT / TOP: Restringe o total de linhas exibidas.

3. Exemplos Práticos de Uso

-- Cursos que possuem mais de 30 alunos matriculados
SELECT id_curso, COUNT(*) AS total_matriculas
FROM matriculas
GROUP BY id_curso
HAVING COUNT(*) > 30;

-- Departamentos onde a soma dos salários ultrapassa R$ 50.000,00
SELECT id_departamento, SUM(salario) AS folha_pagamento
FROM funcionarios
GROUP BY id_departamento
HAVING SUM(salario) > 50000.00;

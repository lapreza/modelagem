Semana 9 — Aula 3

Consultas Complexas com SQL

Desafios de Consultas Avançadas

Em cenários de Business Intelligence (BI) e desenvolvimento de software corporativo, extrair informações relevantes exige combinar múltiplos conceitos de SQL em uma única instrução estruturada.

1. Expressões de Tabela Comuns (CTEs) com `WITH`

A cláusula WITH cria tabelas temporárias nomeadas (CTEs - Common Table Expressions) que tornam consultas complexas significativamente mais legíveis e fáceis de manter do que subconsultas profundamente aninhadas. 

-- Calculando o desempenho dos alunos e filtrando apenas os que superam a média do curso
WITH MediaPorCurso AS (
    SELECT id_curso, AVG(nota_final) AS media_curso
    FROM matriculas
    GROUP BY id_curso
),
AlunosDestaque AS (
    SELECT m.id_aluno, m.id_curso, m.nota_final, c.media_curso
    FROM matriculas m
    INNER JOIN MediaPorCurso c ON m.id_curso = c.id_curso
    WHERE m.nota_final > c.media_curso
)
SELECT a.nome_aluno, d.nota_final, d.media_curso
FROM AlunosDestaque d
INNER JOIN alunos a ON d.id_aluno = a.id_aluno;

2. Funções de Janela (Window Functions)

As Window Functions (como ROW_NUMBER(), RANK(), DENSE_RANK() e SUM() OVER()) realizam cálculos através de um conjunto de linhas relacionadas sem agrupar o resultado final em uma única linha. 

-- Ranking dos alunos com maior nota dentro de cada curso
SELECT 
    a.nome_aluno,
    c.nome_curso,
    m.nota_final,
    ROW_NUMBER() OVER (
        PARTITION BY m.id_curso 
        ORDER BY m.nota_final DESC
    ) AS posicao_ranking
FROM matriculas m
INNER JOIN alunos a ON m.id_aluno = a.id_aluno
INNER JOIN cursos c ON m.id_curso = c.id_curso;

3. Expressões Condicionais (`CASE WHEN`)

A instrução CASE WHEN introduz a lógica condicional (If-Else) diretamente nas consultas SELECT, permitindo categorizar valores ou transformar dados em tempo de execução. 

-- Categorizando a situação dos alunos com base na nota
SELECT 
    nome_aluno,
    nota_final,
    CASE 
        WHEN nota_final >= 7.0 THEN 'Aprovado'
        WHEN nota_final >= 5.0 THEN 'Recuperação'
        ELSE 'Reprovado'
    END AS status_aluno
FROM matriculas;

Dica de Organização: Divida consultas complexas utilizando CTEs (WITH) e valide cada bloco de código separadamente antes de integrar o resultado final.

  1. Qual é a principal vantagem de utilizar **Common Table Expressions (CTEs)** com a cláusula WITH em comparação com subconsultas tradicionais?
  2. Explique a diferença entre uma função de agregação tradicional com GROUP BY e uma **Window Function** com a cláusula OVER().
  3. Escreva uma consulta SQL utilizando a instrução CASE WHEN para criar uma coluna chamada faixa_etaria na tabela alunos, classificando alunos com menos de 18 anos como 'Menor de Idade' e os demais como 'Maior de Idade'.

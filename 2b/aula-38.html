Semana 10 — Aula 2

Atualização de Dados (UPDATE)

O Comando UPDATE

O comando UPDATE é utilizado para modificar o conteúdo de um ou mais campos em registros que já existem no banco de dados.

Sintaxe Básica:

UPDATE nome_da_tabela
SET coluna1 = valor1, coluna2 = valor2, ...
WHERE condicao;

1. O Perigo da Omissão da Cláusula WHERE

Se a cláusula WHERE for omitida na execução do UPDATE, a alteração será aplicada em **todas as linhas da tabela**.

Cuidado Operacional: Antes de rodar um comando UPDATE em produção, execute um SELECT com a exata mesma cláusula WHERE para conferir antecipadamente quais registros serão alterados.

-- Atualizando o e-mail de um único aluno especificando sua chave primária (Seguro)
UPDATE alunos
SET email = 'lucas.pereira@email.com'
WHERE id_aluno = 15;

2. Atualizações com Expressões Matemáticas e Múltiplos Campos

Podemos reajustar valores numéricos aplicando operações diretamente no valor atual do campo, bem como atualizar vários atributos simultaneamente numa mesma instrução. 

-- Reajustando o valor da mensalidade de todos os alunos do curso de 'Informática' em 10%
UPDATE cursos
SET mensalidade = mensalidade * 1.10,
    data_atualizacao = CURRENT_DATE
WHERE nome_curso = 'Informática';

3. Atualização Baseada em Subconsultas

É possível utilizar o resultado de uma subconsulta para definir o novo valor de um campo com base em dados de outra tabela. 

-- Definindo o status do aluno como 'Em Risco' se sua nota for menor que a média do curso
UPDATE matriculas
SET status = 'Em Risco'
WHERE nota_final < (
    SELECT AVG(nota_final) 
    FROM matriculas 
    WHERE id_curso = matriculas.id_curso
);

Semana 10 — Aula 3

Exclusão de Dados (DELETE e TRUNCATE)

O Comando DELETE

O comando DELETE pertence à DML (Data Manipulation Language) e é utilizado para remover registros específicos de uma tabela com base em condições lógicas informadas na cláusula WHERE. 

-- Excluindo um único registro através da Chave Primária
DELETE FROM alunos 
WHERE id_aluno = 42;

-- Excluindo múltiplos registros baseados em uma condição
DELETE FROM matriculas 
WHERE situacao = 'Cancelada' AND data_cancelamento < '2025-01-01';

Risco de Exclusão Total: Executar um comando DELETE FROM nome_da_tabela; sem a cláusula WHERE apagará todos os registros da tabela, linha por linha, gravando a remoção de cada registro individual no log de transações do banco.

1. Comparação: DELETE vs TRUNCATE TABLE

Para esvaziar totalmente uma tabela, a SQL oferece o comando DDL TRUNCATE TABLE. Apesar de atingirem o mesmo resultado final visual, a sua arquitetura interna é completamente diferente:

  • DELETE (DML): Apaga linha por linha. Suporta a cláusula WHERE. Dispara Triggers de exclusão (AFTER DELETE / BEFORE DELETE) e mantém os ponteiros de colunas auto-incrementais (AUTO_INCREMENT).
  • TRUNCATE TABLE (DDL): Desaloca diretamente as páginas de memória/disco da tabela. Não aceita filtro WHERE, não dispara Triggers e reinicia (reseta) o contador de colunas auto-incrementais para o valor inicial (1). É extremamente mais rápido em tabelas grandes.
-- Esvaziando a tabela rapidamente e resetando IDs auto-incrementais (DDL)
TRUNCATE TABLE logs_sistema;

2. Integridade Referencial e Exclusão em Cascata

Ao tentar excluir um registro pai cuja chave primária é referenciada por uma chave estrangeira em outra tabela, o SGBD bloqueará a operação com erro de integridade referencial, a menos que uma regra especial de exclusão tenha sido definida na criação da Foreign Key:

  • ON DELETE RESTRICT / NO ACTION (Padrão): Impede a exclusão do pai se houver filhos cadastrados.
  • ON DELETE CASCADE: Exclui automaticamente todos os registros filhos vinculados quando o registro pai for removido.
  • ON DELETE SET NULL: Mantém os registros filhos, mas altera os campos da Foreign Key para NULL.

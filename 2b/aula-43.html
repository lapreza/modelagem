Semana 11 — Aula 3

Importação e Exportação de Dados

Intercâmbio de Dados em Bancos Relacionais

A Importação e Exportação de Dados permite mover grandes volumes de informação entre bancos de dados, planilhas eletrónicas, sistemas legados e aplicações web. O formato mais universalmente utilizado para essa troca é o CSV (Comma-Separated Values), além de formatos semiestruturados como JSON e XML.

1. Importação de Dados (Bulk Load)

Para carregar arquivos de texto massivos (com centenas de milhares de linhas) sem a lentidão de múltiplos comandos INSERT, os SGBDs disponibilizam instruções nativas otimizadas.

Exemplo no PostgreSQL (Comando COPY):

-- Importando um arquivo CSV para a tabela 'alunos'
COPY alunos(id_aluno, nome_aluno, email, curso)
FROM '/tmp/alunos_novos.csv'
WITH (FORMAT csv, HEADER true, DELIMITER ',');

Exemplo no MySQL (LOAD DATA INFILE):

-- Carregando dados de arquivo CSV no MySQL
LOAD DATA INFILE '/var/lib/mysql-files/alunos.csv'
INTO TABLE alunos
FIELDS TERMINATED BY ',' 
ENCLOSED BY '"'
LINES TERMINATED BY '\n'
IGNORE 1 ROWS; -- Ignora a linha de cabeçalho

2. Exportação de Dados

Exportar os resultados de consultas em formatos legíveis facilita a geração de relatórios e a alimentação de ferramentas de Business Intelligence (BI). 

-- Exportando o resultado de uma consulta SELECT para um arquivo CSV (PostgreSQL)
COPY (
    SELECT nome_aluno, email, curso 
    FROM alunos 
    WHERE curso = 'Informática'
) TO '/tmp/alunos_informatica.csv' WITH (FORMAT csv, HEADER true);

Cuidados com Codificação e Delimitadores: Certifique-se de alinhar a codificação de caracteres (ex: UTF-8) e o caractere delimitador (vírgula , ou ponto e vírgula ;) entre a origem e o destino para evitar corrupção de acentuação e quebra de colunas.

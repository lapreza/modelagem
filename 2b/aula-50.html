Semana 13 — Aula 2

UPDATE em Tabelas Relacionadas

Atualizações Condicionadas a Dados Relacionados

Muitas vezes, a necessidade de alterar os dados de uma tabela depende de condições armazenadas em outra tabela relacionada. O SQL permite realizar modificações dinâmicas integrando junções (JOIN) ou subconsultas na instrução UPDATE.

1. Sintaxe de UPDATE com JOIN (SGBDs Multi-Tabela)

Em bancos como MySQL e SQL Server, é possível vincular tabelas diretamente na cláusula UPDATE através de INNER JOIN ou LEFT JOIN. 

-- Reajustando em 15% o valor das matrículas apenas dos alunos matriculados no curso de 'Informática'
UPDATE matriculas m
INNER JOIN cursos c ON m.id_curso = c.id_curso
SET m.valor_mensalidade = m.valor_mensalidade * 1.15
WHERE c.nome_curso = 'Informática';

2. Sintaxe com Subconsultas (PostgreSQL / ANSI SQL)

No PostgreSQL e no padrão ANSI estrito, utiliza-se a cláusula FROM adicional ou subconsultas filtrantes na cláusula WHERE para alcançar o mesmo resultado. 

-- Atualização utilizando a cláusula FROM (PostgreSQL)
UPDATE matriculas m
SET valor_mensalidade = m.valor_mensalidade * 1.15
FROM cursos c
WHERE m.id_curso = c.id_curso
  AND c.nome_curso = 'Informática';

-- Atualização utilizando subconsulta na cláusula WHERE
UPDATE matriculas
SET situacao = 'Inativa'
WHERE id_aluno IN (
    SELECT id_aluno 
    FROM alunos 
    WHERE status_cadastral = 'Desligado'
);

Cuidado com ON UPDATE CASCADE: Ao alterar o valor de uma Chave Primária (PK) na tabela pai, a instrução propagará automaticamente o novo código para todas as Chaves Estrangeiras (FK) filhas apenas se a restrição tiver sido configurada com ON UPDATE CASCADE.

3. Atualizações Correlacionadas (Calculando Valores a partir do Filho)

Podemos atualizar um campo agregador no registro pai com base no somatório ou contagem de seus registros filhos. 

-- Atualizando o total de alunos matriculados diretamente na tabela de cursos
UPDATE cursos c
SET total_alunos = (
    SELECT COUNT(*) 
    FROM matriculas m 
    WHERE m.id_curso = c.id_curso
);

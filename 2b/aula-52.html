Semana 13 — Aula 4

Triggers e Automação em Banco de Dados

O que é um Trigger (Gatilho)?

Um Trigger é um procedimento especial gravado no servidor de banco de dados que é executado automaticamente ("disparado") sempre que um evento DML específico (INSERT, UPDATE ou DELETE) ocorre em uma determinada tabela.

1. Momentos de Disparo e Eventos

A definição de um gatilho exige especificar o evento que o dispara e o momento da execução:

  • BEFORE: Disparado antes que a alteração seja gravada no disco. Ideal para validações complexas e formatação prévia de dados.
  • AFTER: Disparado depois que a alteração é efetivada na tabela. Recomendado para gravação de logs de auditoria, atualizações em cascata e sincronizações.

2. As Pseudotabelas NEW e OLD

Dentro do corpo de um gatilho, o SGBD disponibiliza as variáveis especiais NEW e OLD para acessar o estado dos dados:

INSERT: Possui apenas a variável NEW (representa o novo registro sendo inserido).

UPDATE: Possui OLD (dados originais antes da alteração) e NEW (novos dados atribuídos).

DELETE: Possui apenas a variável OLD (dados do registro que está a ser apagado).

-- Exemplo de Trigger de Auditoria (AFTER UPDATE)
DELIMITER //
CREATE TRIGGER trg_AuditAlteracaoAluno
AFTER UPDATE ON alunos
FOR EACH ROW
BEGIN
    -- Se o e-mail do aluno for alterado, grava o histórico na tabela de log
    IF OLD.email <> NEW.email THEN
        INSERT INTO log_auditoria (tabela, id_registro, acao, valor_antigo, valor_novo, data_alteracao)
        VALUES ('alunos', NEW.id_aluno, 'ALTERACAO_EMAIL', OLD.email, NEW.email, NOW());
    END IF;
END //
DELIMITER ;

3. Validação de Dados com BEFORE INSERT

Gatilhos do tipo BEFORE podem interromper a execução do comando DML gerando uma exceção de erro personalizada. 

-- Impede a inserção de mensalidades com valor negativo
DELIMITER //
CREATE TRIGGER trg_ValidaMensalidade
BEFORE INSERT ON cursos
FOR EACH ROW
BEGIN
    IF NEW.mensalidade < 0 THEN
        SIGNAL SQLSTATE '45000' 
        SET MESSAGE_TEXT = 'Erro: A mensalidade do curso não pode ser negativa.';
    END IF;
END //
DELIMITER ;

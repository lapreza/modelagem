Aula 60: SQL Básico para SGBD Relacional

Revise e consolide a sintaxe essencial da linguagem SQL para criar bancos e tabelas (DDL) e realizar operações fundamentais de inserção, consulta, atualização e exclusão de registros (CRUD / DML).

1. Subconjuntos da Linguagem SQL

A SQL (Structured Query Language) é a linguagem padrão para comunicação com SGBDs relacionais. Seus comandos são organizados em grupos funcionais conforme o objetivo da operação:

Sigla Nome Finalidade Comandos Principais
DDL Data Definition Language Definir e modificar a estrutura física do banco e tabelas. CREATE, ALTER, DROP, TRUNCATE
DML Data Manipulation Language Inserir, alterar e remover os registros armazenados nas tabelas. INSERT, UPDATE, DELETE
DQL Data Query Language Consultar, filtrar e ordenar informações do banco. SELECT
DCL Data Control Language Controlar permissões e segurança de acesso dos usuários. GRANT, REVOKE
TCL Transaction Control Language Gerenciar transações garantindo atomicidade e consistência. COMMIT, ROLLBACK, SAVEPOINT

2. Criando a Estrutura com DDL

Antes de armazenar qualquer informação, criamos o banco de dados (schema) e suas tabelas definindo os tipos de dados e restrições de integridade:

-- 1. Criação e seleção do banco de dados
CREATE DATABASE loja_tech;
USE loja_tech;

-- 2. Criação da tabela de produtos
CREATE TABLE produtos (
    id_produto INT PRIMARY KEY AUTO_INCREMENT,
    nome VARCHAR(100) NOT NULL,
    categoria VARCHAR(50) DEFAULT 'Geral',
    preco DECIMAL(10, 2) NOT NULL,
    estoque INT NOT NULL DEFAULT 0
);

3. Operações Básicas de Manipulação e Consulta (CRUD)

Com a estrutura criada, utilizamos os quatro pilares de manipulação de dados no dia a dia:

Inserindo Registros (INSERT)

INSERT INTO produtos (nome, categoria, preco, estoque)
VALUES 
    ('Teclado Mecânico RGB', 'Periféricos', 289.90, 15),
    ('Monitor 24 Polegadas', 'Monitores', 899.00, 8),
    ('Cabo HDMI 2.1', 'Acessórios', 45.50, 40);

Consultando Registros (SELECT + WHERE + ORDER BY)

-- Seleciona produtos com preço acima de R$ 100, ordenados do mais caro ao mais barato
SELECT nome, categoria, preco, estoque
FROM produtos
WHERE preco > 100.00
ORDER BY preco DESC;

Atualizando e Excluindo Registros (UPDATE e DELETE)

-- Atualiza o preço e estoque de um produto específico
UPDATE produtos
SET preco = 259.90, estoque = estoque - 1
WHERE id_produto = 1;

-- Remove um registro específico pela chave primária
DELETE FROM produtos
WHERE id_produto = 3;
Atenção Crítica: Nunca execute UPDATE ou DELETE sem a cláusula WHERE em ambientes de produção, pois isso alterará ou apagará todos os registros da tabela de uma só vez.

4. Exercícios de Fixação

Pratique a escrita e interpretação de comandos SQL básicos:

1. Escreva um comando SQL para listar apenas o nome e o estoque dos produtos da categoria 'Periféricos' que possuam menos de 10 unidades em estoque.

Ver resposta comentada
SELECT nome, estoque FROM produtos WHERE categoria = 'Periféricos' AND estoque < 10;

2. Qual a diferença prática entre os comandos DELETE FROM produtos; e DROP TABLE produtos;?

Ver resposta comentada
O comando DELETE (DML) remove apenas as linhas/registros da tabela, mantendo sua estrutura, colunas e índices intactos para novas inserções. Já o DROP TABLE (DDL) destrói completamente a tabela inteira (dados + estrutura) do banco de dados.

3. Para que serve o tipo de dado DECIMAL(10, 2) utilizado na coluna preco?

Ver resposta comentada
Armazena números decimais exatos com até 10 dígitos no total, sendo 2 dígitos reservados após a vírgula (centavos), evitando erros de arredondamento típicos de tipos de ponto flutuante (FLOAT) em valores monetários.

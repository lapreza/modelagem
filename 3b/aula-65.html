Aula 65: Cláusula SELECT Básica

Domine a anatomia fundamental de uma consulta SQL: projeção de colunas, apelidos (AS), eliminação de duplicatas (DISTINCT), filtros condicionais avançados (WHERE, IN, BETWEEN, LIKE, IS NULL), ordenação (ORDER BY) e paginação (LIMIT/OFFSET).

1. Anatomia e Ordem de Execução do SELECT

O comando SELECT (pertencente à DQL — Data Query Language) é a instrução mais utilizada em bancos de dados relacionais. Embora escrevamos as cláusulas em uma sequência específica, o motor do SGBD as processa internamente em uma ordem lógica distinta:

Ordem de Escrita Ordem Lógica no SGBD Função da Cláusula
1. SELECT 4º. SELECT Escolhe quais colunas ou expressões calculadas serão exibidas.
2. FROM 1º. FROM Identifica a(s) tabela(s) de origem dos dados.
3. WHERE 2º. WHERE Filtra as linhas antes de qualquer projeção ou ordenação.
4. DISTINCT 3º. DISTINCT Remove linhas duplicadas do conjunto resultante.
5. ORDER BY 5º. ORDER BY Ordena o resultado final de forma ascendente (ASC) ou descendente (DESC).
6. LIMIT / OFFSET 6º. LIMIT / OFFSET Restringe a quantidade de registros retornados (paginação).
Por que a ordem lógica importa? Como o WHERE é executado antes do SELECT, você não pode usar um apelido (alias) criado no SELECT dentro da cláusula WHERE, mas pode usá-lo livremente no ORDER BY!

2. Projeção de Colunas, Apelidos (AS) e DISTINCT

Evite usar SELECT * em aplicações de produção. Projetar apenas as colunas necessárias economiza banda de rede, memória e permite ao SGBD aproveitar melhor os índices.

-- Projeção específica com cálculos e apelidos (Aliases)
SELECT 
    nome AS produto,
    preco AS preco_unitario,
    estoque,
    (preco * estoque) AS valor_total_estoque
FROM produtos;

-- Listando apenas as cidades distintas (sem repetição) onde há clientes
SELECT DISTINCT cidade, estado
FROM clientes
ORDER BY estado ASC, cidade ASC;

3. Operadores Essenciais na Cláusula WHERE

Além dos operadores relacionais padrão (=, <> ou !=, >, <, >=, <=) e lógicos (AND, OR, NOT), a SQL oferece operadores expressivos para filtros precisos:

-- BETWEEN: filtro por faixa inclusiva (valores e datas)
SELECT id_pedido, data_pedido, valor_total
FROM pedidos
WHERE valor_total BETWEEN 150.00 AND 500.00;

-- IN: comparação contra uma lista de valores
SELECT nome, cidade
FROM clientes
WHERE cidade IN ('Sumaré', 'Americana', 'Hortolândia');

-- LIKE: busca por padrões de texto (% = qualquer sequência, _ = 1 caractere)
SELECT nome, email
FROM clientes
WHERE nome LIKE 'Maria%';

-- IS NULL / IS NOT NULL: verificação correta de ausência de valor
SELECT id_emprestimo, data_retirada
FROM emprestimos
WHERE data_devolucao IS NULL;
Armadilha Clássica com NULL: Nunca escreva WHERE data_devolucao = NULL! Em SQL, NULL representa um valor desconhecido, e qualquer comparação com = ou != resulta em UNKNOWN (falso no filtro). Utilize sempre IS NULL ou IS NOT NULL.

4. Ordenação e Paginação de Resultados

Para construir rankings ("Top 5 produtos mais caros") ou paginar resultados em sistemas web (página 1, página 2...), combinamos ORDER BY, LIMIT e OFFSET:

-- Top 5 produtos mais caros em estoque
SELECT nome, preco
FROM produtos
WHERE estoque > 0
ORDER BY preco DESC
LIMIT 5;

-- Paginação: exibindo 10 registros por página (Página 3 -> pula os 20 primeiros)
SELECT id_cliente, nome
FROM clientes
ORDER BY nome ASC
LIMIT 10 OFFSET 20;

5. Exercícios de Fixação

Pratique a construção de consultas SELECT básicas:

1. Por que a consulta SELECT nome, preco * 1.10 AS novo_preco FROM produtos WHERE novo_preco > 100; gera um erro de coluna desconhecida na maioria dos SGBDs?

Ver resposta comentada
Porque na ordem lógica de execução, a cláusula WHERE é avaliada antes da cláusula SELECT. Portanto, o apelido novo_preco ainda não existe no momento em que o filtro é executado. A solução é repetir a expressão: WHERE preco * 1.10 > 100.

2. Qual a diferença entre os padrões LIKE 'A%' e LIKE '_A%'?

Ver resposta comentada
O padrão 'A%' encontra textos que começam com a letra A (ex.: Ana, Alberto). Já '_A%' exige exatamente um caractere qualquer na primeira posição e a letra A na segunda posição (ex.: Carlos, Mariana, Paulo).

3. Escreva uma consulta SQL para listar os 3 pedidos mais recentes (pela coluna data_pedido) do cliente com id_cliente = 42.

Ver resposta comentada
SELECT * FROM pedidos WHERE id_cliente = 42 ORDER BY data_pedido DESC LIMIT 3;

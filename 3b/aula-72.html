Aula 72: SELECT com CASE

Aprenda a aplicar lógica condicional (estruturas IF / THEN / ELSE) diretamente em consultas SQL utilizando CASE Simples e CASE Pesquisado para classificar dados, criar agregações condicionais (pivotamento) e definir ordenações customizadas.

1. Lógica Condicional no SQL: Expressão CASE

A expressão CASE ... WHEN ... THEN ... ELSE ... END traz a estrutura condicional if / else if / else das linguagens de programação para dentro da consulta SQL. Ela é avaliada de cima para baixo e retorna o valor correspondente à primeira condição verdadeira encontrada.

Formato Estrutura Sintática Quando Utilizar
CASE Simples CASE coluna
  WHEN 'A' THEN 'Ativo'
  WHEN 'I' THEN 'Inativo'
  ELSE 'Desconhecido'
END		 Quando você compara uma única coluna ou expressão por igualdade exata contra valores fixos.
CASE Pesquisado (Searched) CASE
  WHEN nota >= 7 THEN 'Aprovado'
  WHEN nota >= 5 THEN 'Recuperação'
  ELSE 'Reprovado'
END		 Quando precisa testar faixas de valores (>, <, BETWEEN), valores nulos (IS NULL) ou múltiplas colunas combinadas com AND/OR.
O que acontece se omitir o ELSE? Se nenhuma condição WHEN for satisfeita e não houver cláusula ELSE, a expressão CASE retornará NULL por padrão.

2. Aplicações Práticas: Classificação, Pivotamento e Ordenação

Por ser uma expressão escalar válida em quase qualquer parte da consulta, o CASE pode ser usado no SELECT, dentro de funções de agregação (SUM/COUNT), no GROUP BY e até no ORDER BY:

-- 1. Classificação de faixa de preço no SELECT (CASE Pesquisado)
SELECT 
    nome,
    preco,
    CASE
        WHEN preco < 50.00 THEN 'Econômico'
        WHEN preco BETWEEN 50.00 AND 200.00 THEN 'Intermediário'
        ELSE 'Premium'
    END AS faixa_preco
FROM produtos;

-- 2. Agregação Condicional (Pivotamento): contar pedidos por status em uma única linha
SELECT 
    COUNT(*) AS total_pedidos,
    SUM(CASE WHEN status = 'PAGO' THEN 1 ELSE 0 END) AS qtd_pagos,
    SUM(CASE WHEN status = 'PENDENTE' THEN 1 ELSE 0 END) AS qtd_pendentes,
    SUM(CASE WHEN status = 'CANCELADO' THEN valor_total ELSE 0 END) AS valor_cancelado
FROM pedidos;

-- 3. Ordenação Customizada (não alfabética) no ORDER BY
SELECT id_chamado, titulo, prioridade
FROM chamados_suporte
ORDER BY 
    CASE prioridade
        WHEN 'CRITICA' THEN 1
        WHEN 'ALTA'    THEN 2
        WHEN 'MEDIA'   THEN 3
        ELSE 4
    END ASC;
Armadilha com NULL no CASE Simples: Nunca escreva CASE coluna WHEN NULL THEN ...! Como no SQL NULL = NULL resulta em UNKNOWN, essa comparação nunca será verdadeira. Para testar valores nulos, utilize sempre o CASE Pesquisado: CASE WHEN coluna IS NULL THEN ... END.

3. Atalhos Condicionais no Padrão SQL: COALESCE e NULLIF

Para casos condicionais muito frequentes envolvendo valores nulos, o SQL padrão oferece duas funções enxutas que funcionam como atalhos internos para expressões CASE:

  • COALESCE(val1, val2, ..., valN): Retorna o primeiro valor não nulo da lista. Equivalente a CASE WHEN val1 IS NOT NULL THEN val1 ELSE val2 END. Muito usado para substituir NULL por zero ou texto padrão (ex.: COALESCE(telefone, 'Não informado')).
  • NULLIF(val1, val2): Retorna NULL se val1 = val2; caso contrário, retorna val1. Essencial para evitar divisão por zero: receita / NULLIF(qtd_vendas, 0).

4. Exercícios de Fixação

Avalie seu raciocínio com expressões condicionais em SQL:

1. Analise o trecho: CASE WHEN nota >= 5 THEN 'Recuperação' WHEN nota >= 7 THEN 'Aprovado' ELSE 'Reprovado' END. Se um aluno tirou nota 9.0, qual texto será retornado e por quê?

Ver resposta comentada
Será retornado 'Recuperação'! Como a expressão CASE avalia as condições de cima para baixo e para na primeira verdadeira, 9.0 >= 5 é verdadeiro logo na primeira linha. Para corrigir, deve-se testar sempre do critério mais restritivo para o mais amplo (nota >= 7 primeiro).

2. Por que a expressão CASE data_entrega WHEN NULL THEN 'Em trânsito' ELSE 'Entregue' END sempre retorna 'Entregue' mesmo quando data_entrega está vazia?

Ver resposta comentada
Porque o CASE Simples realiza testes de igualdade (data_entrega = NULL), e em SQL qualquer comparação com = NULL retorna UNKNOWN (falso). A forma correta usa o CASE Pesquisado: CASE WHEN data_entrega IS NULL THEN 'Em trânsito' ELSE 'Entregue' END.

3. Como evitar um erro de divisão por zero ao calcular valor_total / quantidade_itens caso algum registro possua quantidade_itens = 0?

Ver resposta comentada
Utilizando valor_total / NULLIF(quantidade_itens, 0) (ou um CASE WHEN quantidade_itens = 0 THEN NULL ELSE valor_total / quantidade_itens END). Quando quantidade_itens for 0, NULLIF transforma o divisor em NULL, fazendo o resultado da divisão ser NULL em vez de travar a consulta com erro.

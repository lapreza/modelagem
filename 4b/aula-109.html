Semana 28 — Aula 1

Aplicações Práticas de MongoDB

O MongoDB no Mercado de Software Moderno

Pela sua natureza flexível e orientada a documentos BSON, o MongoDB tornou-se a escolha padrão para aplicações que necessitam de iteração rápida de produto, manipulação de dados semiestruturados e escalabilidade horizontal transparente.

1. Catálogo Polimórfico de Produtos (E-Commerce)

Num e-commerce tradicional em SQL, armazenar produtos com atributos completamente distintos (ex.: um smartphone tem "RAM" e "tela", enquanto um livro tem "páginas" e "autor") exige tabelas EAV (Entity-Attribute-Value) complexas e com baixo desempenho.

No MongoDB, o esquema dinâmico permite que cada produto viva na mesma coleção produtos com a sua própria estrutura natural: 

// Documento de um Smartphone
{
  "_id": "prod_100",
  "nome": "Smartphone Galaxy",
  "categoria": "Eletrônicos",
  "atributos": { "ram": "8GB", "armazenamento": "256GB" }
}

// Documento de um Livro na mesma coleção
{
  "_id": "prod_200",
  "nome": "Entendendo Algoritmos",
  "categoria": "Livros",
  "atributos": { "autor": "Aditya Bhargava", "paginas": 264 }
}

2. Gestão de Conteúdo e Perfis de Utilizador (CMS)

Sistemas de gerenciamento de conteúdo (blogs, portais de notícias, plataformas de e-learning) utilizam documentos embutidos para salvar o post com os seus comentários, tags e histórico de revisões num único registro, realizando a leitura da página com **apenas 1 operação de I/O**.

Vantagem Operacional: Elimina a necessidade de múltiplos JOINs pesados entre tabelas de Posts, Comentários, Autores e Tags.

3. Análise de Dados e Geolocalização

O MongoDB possui suporte nativo a índices geoespaciais (2dsphere), permitindo consultar estabelecimentos ou motoristas num raio de distância usando a especificação GeoJSON: 

// Criando um índice geoespacial
db.restaurantes.createIndex({ localizacao: "2dsphere" });

// Buscando restaurantes num raio de 2km (2000 metros) da posição do utilizador
db.restaurantes.find({
  localizacao: {
    $near: {
      $geometry: { type: "Point", coordinates: [-47.17, -22.82] },
      $maxDistance: 2000
    }
  }
});

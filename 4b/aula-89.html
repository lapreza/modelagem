Semana 23 — Aula 1

Introdução ao MongoDB

O que é o MongoDB?

O MongoDB é o banco de dados NoSQL orientado a documentos mais popular e utilizado do mundo. Criado pela 10gen (atual MongoDB Inc.) em 2007, foi desenvolvido para ser altamente escalável, flexível e nativamente compatível com aplicações web e mobile modernas.

Orientado a Documentos: Em vez de armazenar dados em tabelas rígidas compostas por linhas e colunas, o MongoDB armazena dados em documentos autossuficientes no formato BSON (Binary JSON).

Mapeamento de Conceitos: Relacional vs. MongoDB

Para quem vem do mundo SQL, a tabela a seguir correlaciona os termos fundamentais dos dois paradigmas:

Conceito Relacional (SQL) Conceito no MongoDB
Banco de Dados (Database) Banco de Dados (Database)
Tabela (Table) Coleção (Collection)
Linha / Registro (Row / Record) Documento (Document)
Coluna (Column) Campo (Field)
Chave Primária (Primary Key - PK) Campo _id (gerado automaticamente via ObjectId)
Junção (JOIN) Documentos Embutidos ou $lookup

O Formato BSON e o Campo ObjectId

Internamente, o MongoDB converte os documentos JSON recebidos para o formato **BSON (Binary JSON)**. O BSON adiciona suporte a tipos de dados estendidos (como datas, números inteiros de 64 bits e dados binários) e otimiza a velocidade de varredura e indexação.

Exemplo de Documento BSON no MongoDB:

{
  "_id": ObjectId("65e9b8f21c9d4b001a2b3c4d"),
  "nome": "Curso de Banco de Dados",
  "categoria": "Tecnologia",
  "cargaHoraria": 80,
  "ativo": true,
  "dataCriacao": ISODate("2026-03-01T10:00:00Z"),
  "tags": ["sql", "nosql", "mongodb"]
}

O Campo _id: Todo documento armazenado em uma coleção do MongoDB requer obrigatoriamente uma chave primária única chamada _id. Se não for especificada manualmente na inserção, o MongoDB gera um valor padrão do tipo ObjectId (composto por 12 bytes que incluem timestamp, ID da máquina, ID do processo e contador incremental).

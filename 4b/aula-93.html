Semana 24 — Aula 1

Operações CRUD no MongoDB

O que é o CRUD?

A sigla CRUD representa as quatro operações essenciais de persistência de dados em qualquer sistema de armazenamento: Create (Inserção), Read (Leitura), Update (Atualização) e Delete (Remoção).

No MongoDB Shell (mongosh) ou através de drivers de linguagens (Python, Node.js, C#), as operações operam diretamente sobre **coleções** utilizando objetos BSON.

1. Inserção de Documentos (Create)

Inserir um Único Documento (insertOne)

db.alunos.insertOne({
  nome: "Lucas Mendes",
  curso: "Desenvolvimento de Sistemas",
  idade: 19,
  habilidades: ["Python", "SQL"]
});

Inserir Múltiplos Documentos (insertMany)

db.alunos.insertMany([
  { nome: "Beatriz Lima", curso: "Informática", idade: 18 },
  { nome: "Carla Souza", curso: "Desenvolvimento de Sistemas", idade: 21 }
]);

2. Leitura de Documentos (Read)

Consultar Todos ou Filtrar (find)

-- Retorna todos os documentos da coleção
db.alunos.find();

-- Buscar apenas alunos do curso 'Informática'
db.alunos.find({ curso: "Informática" });

-- Buscar um único documento que atenda ao filtro
db.alunos.findOne({ nome: "Beatriz Lima" });

3. Atualização de Documentos (Update)

No MongoDB, a atualização utiliza operadores atômicos como $set (para alterar/adicionar campos) e $inc (para incrementar valores numéricos). 

-- Atualizar a idade de um aluno específico ($set)
db.alunos.updateOne(
  { nome: "Lucas Mendes" },
  { $set: { idade: 20, ativo: true } }
);

-- Incrementar a idade de todos os alunos do curso de Sistemas em +1 ano ($inc)
db.alunos.updateMany(
  { curso: "Desenvolvimento de Sistemas" },
  { $inc: { idade: 1 } }
);

4. Remoção de Documentos (Delete)

-- Remover um único documento
db.alunos.deleteOne({ nome: "Carla Souza" });

-- Remover todos os documentos que atendem a um critério
db.alunos.deleteMany({ idade: { $gt: 25 } });

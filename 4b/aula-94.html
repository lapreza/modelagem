Semana 24 — Aula 2

Consultas Avançadas no MongoDB

Operadores de Comparação e Lógicos

Para construir filtros sofisticados no método find(), o MongoDB disponibiliza operadores prefixados com o símbolo $.

Operadores de Comparação:

  • $gt (Greater Than) / $gte (Greater Than or Equal): Maior que / Maior ou igual.
  • $lt (Less Than) / $lte (Less Than or Equal): Menor que / Menor ou igual.
  • $ne (Not Equal): Diferente de.
  • $in / $nin: Pertence / Não pertence a um array de valores.
-- Produtos com preço entre R$ 100 e R$ 500
db.produtos.find({
  preco: { $gte: 100, $lte: 500 }
});

-- Alunos que pertencem aos cursos 'Informática' ou 'Redes'
db.alunos.find({
  curso: { $in: ["Informática", "Redes"] }
});

Operadores Lógicos ($and, $or, $not):

-- Alunos ativos E com idade maior ou igual a 18
db.alunos.find({
  $and: [
    { ativo: true },
    { idade: { $gte: 18 } }
  ]
});

-- Produtos da categoria 'Eletrônicos' OU com preço menor que R$ 50
db.produtos.find({
  $or: [
    { categoria: "Eletrônicos" },
    { preco: { $lt: 50 } }
  ]
});

Projeção, Ordenação e Paginação

1. Projeção (Selecionar apenas campos específicos)

O segundo argumento do find() define os campos a serem retornados (1 para incluir, 0 para omitir):

-- Retornar apenas nome e email (omitindo o _id padrão)
db.alunos.find({}, { nome: 1, email: 1, _id: 0 });

2. Ordenação (sort), Limite (limit) e Pulo (skip)

-- Ordenar por idade decrescente (-1) e pegar os 5 mais velhos
db.alunos.find().sort({ idade: -1 }).limit(5);

-- Paginação: Pular os primeiros 10 registros e limitar aos próximos 10 (Página 2)
db.alunos.find().skip(10).limit(10);

Introdução ao Aggregation Framework

O Aggregation Framework é a ferramenta analítica do MongoDB para processar dados em etapas organizadas num fluxo contínuo conhecido como Pipeline de Agregação.

Principais Etapas do Pipeline:

$match: Filtra documentos (semelhante ao WHERE no SQL).

$group: Agrupa documentos por uma chave e aplica acumuladores como $sum, $avg, $count (semelhante ao GROUP BY).

$sort: Ordena os resultados agregados.

-- Agrupar alunos por curso e calcular a média de idade de cada curso
db.alunos.aggregate([
  { $match: { ativo: true } },
  { 
    $group: { 
      _id: "$curso", 
      mediaIdade: { $avg: "$idade" },
      totalAlunos: { $sum: 1 } 
    } 
  },
  { $sort: { totalAlunos: -1 } }
]);

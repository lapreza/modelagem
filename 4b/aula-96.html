Semana 24 — Aula 4

Operações e Consultas no Redis

Manipulação de Estruturas no Redis CLI

O Redis suporta comandos específicos para cada tipo de dado em memória. Nesta aula, exploramos as operações avançadas em Hashes, Lists, Sets e Sorted Sets (ZSets).

1. Operações com Hashes (Objetos)

Os Hashes são ideais para representar objetos com múltiplos pares campo-valor sob uma única chave.

-- Armazenar dados do produto ID 500
HMSET produto:500 nome "Monitor 27" preco "1200.00" estoque "15"

-- Buscar apenas o preço do produto
HGET produto:500 preco

-- Incrementar o estoque diretamente no Redis
HINCRBY produto:500 estoque 5

-- Obter todos os campos e valores do objeto
HGETALL produto:500

2. Operações com Lists (Filas e Pilhas)

Permitem manipulação rápida nas extremidades (esquerda e direita), funcionando como filas (FIFO) ou pilhas (LIFO).

-- Adicionar itens na fila de notificações (à direita)
RPUSH fila:notificacoes "email_bem_vindo" "sms_confirmacao"

-- Remover e retornar o primeiro item da fila (à esquerda - FIFO)
LPOP fila:notificacoes

-- Consultar elementos de um intervalo (0 a -1 retorna todos)
LRANGE fila:notificacoes 0 -1

3. Operações com Sets e Sorted Sets (ZSets)

Sets (Conjuntos sem duplicatas):

-- Adicionar tags a um artigo (valores duplicados são ignorados)
SADD artigo:10:tags "nosql" "redis" "banco_de_dados" "nosql"

-- Verificar se uma tag existe no conjunto (Retorna 1 ou 0)
SISMEMBER artigo:10:tags "redis"

Sorted Sets (Conjuntos ordenados por Score):

-- Adicionar jogadores e pontuações ao ranking (ZADD chave score membro)
ZADD ranking:jogadores 1500 "PlayerOne" 2300 "PlayerTwo" 1850 "PlayerThree"

-- Obter os 2 melhores jogadores (ordem decrescente de score)
ZREVRANGE ranking:jogadores 0 1 WITHSCORES

4. Mensageria em Tempo Real: Pub/Sub

O Redis possui um sistema integrado de Publicação/Subscrição para comunicação assíncrona entre microserviços. 

-- Em um terminal (Assinante escutando o canal 'alertas')
SUBSCRIBE canal:alertas

-- Em outro terminal (Publicador enviando mensagem)
PUBLISH canal:alertas "Aviso: Manutenção programada às 22h!"

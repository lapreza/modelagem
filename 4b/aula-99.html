Semana 25 — Aula 3

Escalabilidade no Apache Cassandra

Escalabilidade Linear (Scale-Out)

O Apache Cassandra oferece escalabilidade linear: adicionar 10 novos nós a um cluster existente duplica praticamente a capacidade total de armazenamento e o número de operações por segundo suportadas, sem necessidade de reajustes complexos na aplicação.

Níveis de Consistência Configuráveis (Tunable Consistency)

Uma das características mais marcantes do Cassandra é permitir ajustar o nível de consistência em cada operação individual de leitura ou escrita.

Níveis Comuns de Consistência:

  • ONE: A resposta é considerada com sucesso assim que **pelo menos 1** nó réplica confirmar a operação (Altíssima velocidade, menor consistência).
  • QUORUM: Requer confirmação da **maioria simples** das réplicas no cluster.
  • ALL: Exige que **todas** as réplicas confirmem a operação (Garante consistência estrita, mas perde disponibilidade se 1 nó estiver fora do ar).
  • LOCAL_QUORUM: Exige quórum apenas dos nós localizados no mesmo Data Center da requisição (ideal para cenários multi-datacenter).

A Regra da Consistência Forte (Quorum Rule):

Para garantir que uma leitura sempre retorne o dado mais recente gravado, a soma das réplicas envolvidas na escrita (W) e na leitura (R) deve ser maior que o Fator de Replicação (RF):

W + R > RF

Mecanismos Internos de Tolerância a Falhas

1. Hinted Handoff

Se uma réplica estiver temporariamente inativa durante uma gravação, o nó coordenador armazena uma nota (hint) e envia o dado atualizado assim que o nó inativo voltar à rede.

2. Read Repair

Durante uma leitura que consulta múltiplas réplicas, se o Cassandra detetar uma inconsistência de versão entre os nós, ele retorna o dado mais recente para o cliente e atualiza silenciosamente os nós desatualizados em segundo plano.

-- Configurando o nível de consistência no cqlsh
CONSISTENCY QUORUM;

-- Executando uma consulta garantindo resposta pela maioria das réplicas
SELECT * FROM escola_log.sensores WHERE id_sensor = e7b8c9d0-0000-0000-0000-000000000001;

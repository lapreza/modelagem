Modelagem e Desenvolvimento de Banco de Dados

4º Bimestre — Bancos de Dados NoSQL

Explorando arquiteturas não relacioanais, Big Data, escalabilidade horizontal e ecossistema NoSQL.

Apresentação do Módulo

Bem-vindo ao 4º Bimestre da disciplina de Modelagem e Desenvolvimento de Banco de Dados!

Neste módulo final, saímos do modelo relacional tradicional (SQL) para mergulhar no universo do NoSQL (Not Only SQL). Você aprenderá como modelar dados flexíveis, lidar com grandes volumes de informação (Big Data), garantir alta disponibilidade e utilizar na prática tecnologias líderes de mercado como MongoDB, Apache Cassandra, Redis e Neo4j.

Objetivo Principal: Capacitar você a escolher, modelar, operar, otimizar e proteger bancos de dados não relacionais de acordo com as necessidades específicas de aplicações modernas em nuvem.

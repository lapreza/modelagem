Levantamento de Requisitos e Análise de Dados

O que é o Levantamento de Requisitos?

O levantamento de requisitos é a fase do projeto em que o analista ou desenvolvedor investiga, escuta e documenta exatamente o que o cliente ou a empresa precisa armazenar e gerenciar.

Regra de Ouro: Um erro de interpretação nesta fase custa muito mais caro para ser corrigido quando o banco de dados já estiver populado e em produção.

Técnicas de Coleta de Informações

Para identificar quais dados devem ser guardados no sistema, utilizamos diferentes estratégias:

  • Entrevistas com Usuários: Conversar com quem opera o sistema no dia a dia (caixas, atendentes, gerentes) para entender a rotina.
  • Análise de Documentos Existentes: Examinar notas fiscais impressas, planilhas do Excel, fichas em papel e relatórios antigos da empresa.
  • Observação Direta: Acompanhar o fluxo operacional do negócio para identificar pontos que os usuários esquecem de mencionar nas entrevistas.

Extraindo Entidades e Atributos de um Texto (Mini-Mundo)

Em projetos de banco de dados, chamamos a descrição do problema de Mini-Mundo. Ao ler a regra de negócio, aplicamos regras gramaticais simples para identificar os elementos centrais:

1. Entidades (Substantivos)

Geralmente representam coisas, pessoas, locais ou conceitos sobre os quais queremos guardar dados.
Exemplo: Cliente, Produto, Fornecedor, Venda.

2. Atributos (Características / Adjetivos / Informações)

São as propriedades que descrevem cada entidade.
Exemplo para Cliente: Nome, CPF, Telefone, Endereço.

3. Relacionamentos (Verbos)

Indicam a ação ou associação entre duas entidades.
Exemplo: Cliente compra Produto; Fornecedor entrega Produto.

Estudo de Caso Prático

Cenário: "Uma oficina mecânica precisa controlar o atendimento de seus clientes. Cada cliente possui nome, CPF e telefone. Um cliente pode levar um ou mais veículos para conserto. De cada veículo, a oficina registra a placa, o modelo e o ano."

Análise de Requisitos:

  • Entidades identificadas: Cliente e Veículo.
  • Atributos do Cliente: CPF, Nome, Telefone.
  • Atributos do Veículo: Placa, Modelo, Ano.
  • Relacionamento: Cliente possui/leva Veículo.

Atividade de Fixação

Leia o texto de mini-mundo abaixo e responda às questões no seu caderno:

"Uma farmácia deseja registrar as vendas de medicamentos. Para cada cliente, armazena-se o código, nome e e-mail. Os medicamentos têm um código de barras, nome comercial e preço. Um cliente pode realizar várias compras, e em cada compra é registrada a data e os medicamentos adquiridos."

  1. Liste todas as entidades identificadas no texto.
  2. Quais são os atributos associados à entidade Medicamento?
  3. Qual o relacionamento existente entre Cliente e Medicamento?

Ferramentas de Modelagem de Banco de Dados

Por que usar Ferramentas CASE de Modelagem?

Embora o desenho em papel seja excelente para rascunhar ideias rápidas, o desenvolvimento profissional de banco de dados exige o uso de ferramentas CASE (Computer-Aided Software Engineering). Elas facilitam a criação, edição, padronização e conversão automática dos modelos conceituais e lógicos para código SQL (modelo físico).

Vantagem Principal: Engenharia Direta e Reversa — A capacidade de converter o diagrama visual diretamente em scripts SQL executáveis para o banco de dados.

Principais Ferramentas Utilizadas no Mercado e no Ensino

1. brModelo

Ferramenta brasileira, gratuita e amplamente utilizada em ambiente acadêmico. É focada no ensino do Modelo Entidade-Relacionamento (MER) na notação de Peter Chen e suporta a conversão do Modelo Conceitual diretamente para o Modelo Lógico.

2. MySQL Workbench

Ferramenta oficial da Oracle para MySQL. Permite criar modelos lógicos e físicos avançados, além de se conectar diretamente com o servidor de banco de dados para executar consultas e gerenciar instâncias.

3. Ferramentas Online e Colaborativas (draw.io, Lucidchart)

Ideais para documentação rápida baseada na web, permitindo que múltiplos estudantes ou desenvolvedores editem diagramas em tempo real sem necessidade de instalação local.

Fluxo de Trabalho Prático de Modelagem

  1. Rascunho Inicial: Leitura do mini-mundo e anotações rápidas das entidades e atributos em papel.
  2. Criação Conceitual (Ex.: brModelo): Desenho do diagrama ER clássico com retângulos (entidades), losangos (relacionamentos) e elipses (atributos).
  3. Conversão para Modelo Lógico: Mapeamento das tabelas, definição de tipos de dados básicos, Chaves Primárias (PK) e Estrangeiras (FK).
  4. Geração do Script Físico (.sql): Exportação do script DDL contendo os comandos CREATE TABLE para o banco de dados final.

Prática em Laboratório / Exercício

Utilizando o brModelo (ou uma ferramenta equivalente recomendada pelo professor):

  1. Crie um novo modelo conceitual para um Sistema de Biblioteca.
  2. Insira a entidade LIVRO (atributos: ID_Livro, Titulo, Ano) e a entidade AUTOR (atributos: ID_Autor, Nome).
  3. Conecte as entidades através do relacionamento Escreve.
  4. Utilize a funcionalidade da ferramenta para converter o modelo conceitual para o modelo lógico e observe o resultado gerado.

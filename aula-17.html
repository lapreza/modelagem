Introdução à Linguagem SQL

O que é SQL?

SQL (Structured Query Language ou Linguagem de Consulta Estruturada) é a linguagem padrão internacional (ANSI/ISO) utilizada para interagir com Bancos de Dados Relacionais (SGBDs como MySQL, PostgreSQL, MariaDB, SQLite e SQL Server).

Linguagem Declarativa: Em SQL, você declara o que deseja obter ou modificar no banco de dados, e o mecanismo interno do SGBD se encarrega de definir como executar essa tarefa.

Divisão das Comandos SQL por Sublinguagens

Para facilitar o aprendizado e a organização, os comandos SQL são divididos em subconjuntos conforme a sua finalidade:

1. DDL — Data Definition Language (Linguagem de Definição de Dados)

Comandos que criam, alteram ou excluem a estrutura de tabelas e bancos de dados.

  • CREATE — Cria tabelas ou bancos.
  • ALTER — Modifica a estrutura de uma tabela existente.
  • DROP — Exclui tabelas ou bancos do sistema.

2. DML — Data Manipulation Language (Linguagem de Manipulação de Dados)

Comandos utilizados para inserir, consultar e alterar registros dentro das tabelas.

  • INSERT — Insere novos dados.
  • SELECT — Consulta e lê informações salvas.
  • UPDATE — Atualiza dados existentes.
  • DELETE — Remove dados mantendo a estrutura da tabela.

3. DCL & TCL — Controle de Acesso e Transações

  • DCL (Data Control Language): GRANT e REVOKE (permissões de usuários).
  • TCL (Transaction Control Language): COMMIT e ROLLBACK (controle de transações).

Sintaxe e Boas Práticas de Escrita

  • Palavras-chave em maiúsculas: Por convenção, escrevemos os comandos do SQL em CAIXA ALTA (ex.: SELECT, FROM, WHERE) para diferenciar dos nomes de tabelas e colunas.
  • Ponto e vírgula (;): Encerra cada instrução SQL e é obrigatório na maioria dos SGBDs.
  • Tipos de dados comuns:
    • INT — Números inteiros.
    • VARCHAR(N) — Texto de tamanho variável de até N caracteres.
    • DECIMAL(M,D) / FLOAT — Números fracionários / moedas.
    • DATE / DATETIME — Datas e horários.

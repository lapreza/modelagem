Comandos de Criação de Estruturas (CREATE)

Criando o Banco de Dados

O primeiro passo prático é criar a base de dados (Database) onde armazenaremos as tabelas do nosso sistema. 

-- Criação do banco de dados da escola
CREATE DATABASE escola_tecnica;

-- Seleciona o banco para uso
USE escola_tecnica;

Sintaxe do Comando CREATE TABLE

O comando CREATE TABLE define a estrutura de uma tabela, incluindo nomes de colunas, tipos de dados e **Restrições de Integridade (Constraints)**.

Restrições Mais Comuns:

  • PRIMARY KEY — Define a chave primária única da tabela.
  • FOREIGN KEY ... REFERENCES — Cria o vínculo relacional com outra tabela.
  • NOT NULL — Impede que a coluna fique sem preenchimento.
  • UNIQUE — Garante que não existam dois registros com o mesmo valor na coluna (ex.: CPF, Email).
  • AUTO_INCREMENT (no MySQL) / SERIAL (no PostgreSQL) — Gera o ID numérico automaticamente.

Exemplo Prático Completo em SQL

Abaixo temos a criação de duas tabelas relacionadas (1:N): CURSO e ALUNO.

-- 1. Criação da tabela independente (Lado 1)
CREATE TABLE curso (
    id_curso INT AUTO_INCREMENT PRIMARY KEY,
    nome_curso VARCHAR(100) NOT NULL,
    carga_horaria INT NOT NULL
);

-- 2. Criação da tabela dependente com Chave Estrangeira (Lado N)
CREATE TABLE aluno (
    id_aluno INT AUTO_INCREMENT PRIMARY KEY,
    nome VARCHAR(100) NOT NULL,
    cpf VARCHAR(14) NOT NULL UNIQUE,
    email VARCHAR(100),
    id_curso INT,
    CONSTRAINT fk_aluno_curso 
        FOREIGN KEY (id_curso) REFERENCES curso(id_curso)
);

Atenção à Ordem: A tabela curso precisa de ser criada **antes** da tabela aluno, pois a tabela de alunos faz referência à chave primária de cursos.

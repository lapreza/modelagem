Comandos de Consulta e Leitura (SELECT)

Estrutura Básica do SELECT

O comando SELECT é o mecanismo mais utilizado em SQL. Ele permite extrair dados armazenados em uma ou mais tabelas sem alterar a estrutura ou as informações originais. 

-- Selecionar todas as colunas de uma tabela
SELECT * FROM aluno;

-- Selecionar apenas colunas específicas (Boas práticas)
SELECT nome, email FROM aluno;

Filtrando Resultados com a Cláusula WHERE

A cláusula WHERE é utilizada para limitar os registros devolvidos apenas àqueles que satisfazem condições específicas.

Operadores de Comparação e Lógicos:

  • Operadores relacionais: =, <> (ou !=), >, <, >=, <=.
  • Operadores lógicos: AND, OR, NOT.
  • Busca por padrões: LIKE '%termo%' (o símbolo % é o caractere curinga).
  • Faixa de valores: BETWEEN inicio AND fim.
-- Alunos pertencentes ao curso com ID 2
SELECT nome, email 
FROM aluno 
WHERE id_curso = 2;

-- Busca por parte do nome (qualquer nome que contenha "Silva")
SELECT * 
FROM aluno 
WHERE nome LIKE '%Silva%';

Ordenando e Limitando Resultados

Para organizar visualmente as linhas retornadas, utilizamos a cláusula ORDER BY (que aceita ASC para ascendente e DESC para descendente) e a cláusula LIMIT para controlar a quantidade de linhas recebidas. 

-- Listar alunos em ordem alfabética de A a Z
SELECT nome, email 
FROM aluno 
ORDER BY nome ASC;

-- Buscar os 5 primeiros cursos com maior carga horária
SELECT nome_curso, carga_horaria 
FROM curso 
ORDER BY carga_horaria DESC 
LIMIT 5;

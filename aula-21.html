Semana 6 — Aula 1

Comandos de Deleção de Dados (DELETE)

O Comando DELETE

O comando DELETE é utilizado para apagar uma ou mais linhas de uma tabela mantendo intacta a sua estrutura.

CUIDADO EXTREMO: O comando DELETE FROM tabela; sem a instrução WHERE apagará todos os registos da tabela de uma só vez!

Sintaxe Básica e Uso Prático

-- Apagar um aluno específico pelo seu ID
DELETE FROM aluno 
WHERE id_aluno = 10;

-- Apagar todos os alunos que pertencem ao curso ID 3
DELETE FROM aluno 
WHERE id_curso = 3;

Integridade Referencial e Chaves Estrangeiras

Quando tentamos apagar um registo da tabela pai (ex.: um CURSO) que possui registos dependentes na tabela filho (ex.: ALUNO), o banco de dados bloqueia a operação para impedir que fiquem registos "órfãos".

Ações de Integridade em Foreign Keys:

  • ON DELETE RESTRICT (Padrão): Impede a eliminação do pai enquanto existirem filhos associados.
  • ON DELETE CASCADE: Ao apagar o registo pai, apaga **automaticamente** todos os registos filhos associados a ele.
  • ON DELETE SET NULL: Ao apagar o pai, define o campo da chave estrangeira nos filhos como NULL.
-- Exemplo de FK configurada com eliminação em cascata
CREATE TABLE aluno (
    id_aluno INT PRIMARY KEY,
    nome VARCHAR(100),
    id_curso INT,
    FOREIGN KEY (id_curso) REFERENCES curso(id_curso) ON DELETE CASCADE
);

Diferença entre DELETE, TRUNCATE e DROP

  • DELETE — Remove registos linha a linha, permite cláusula WHERE e pode ser revertido via transação (TCL).
  • TRUNCATE TABLE — Esvazia a tabela rapidamente e reinicia os contadores (AUTO_INCREMENT), mantendo a estrutura.
  • DROP TABLE — Elimina a tabela inteira e a sua estrutura da base de dados.

Atividade Prática

  1. Escreva uma consulta DELETE para remover um aluno da base procurando pelo seu número de CPF.
  2. Explique o perigo de utilizar ON DELETE CASCADE numa relação entre CLIENTE e PEDIDO num sistema comercial real.
  3. Em que situação o comando TRUNCATE TABLE é mais recomendável do que um DELETE sem WHERE?

Semana 7 — Aula 2

Backup e Recuperação de Dados

Importância das Cópias de Segurança (Backup)

O backup é a salvaguarda definitiva de qualquer sistema de informação. Falhas de hardware, ataques de ransomware, erros humanos de eliminação acidental ou desastres naturais podem acontecer a qualquer momento.

Mantra da Administração de Sistemas: "Quem tem um backup, não tem nenhum. Quem tem dois backups, tem um."

Tipos de Backup

1. Backup Lógico (Dump SQL)

Gera um ficheiro de texto (extensão .sql) contendo as instruções de DDL e DML (comandos CREATE TABLE e INSERT) necessárias para reconstruir o banco do zero. É altamente portátil entre diferentes versões do SGBD.

2. Backup Físico

Cópia direta dos ficheiros binários em disco onde o SGBD armazena os dados. É mais rápido de restaurar em bases gigantescas, mas requer que o ambiente de destino seja idêntico.

3. ESTRATÉGIAS DE PERIODICIDADE:

  • Completo (Full): Cópia total da base de dados.
  • Incremental: Copia apenas os dados alterados desde o último backup (seja ele full ou incremental).
  • Diferencial: Copia todos os dados alterados desde o último backup completo.

Comandos Práticos no Terminal (Exemplo MySQL)

Exportando o Banco de Dados (mysqldump):

# Executado no terminal/prompt do sistema operativo (fora do MySQL)
mysqldump -u root -p escola_tecnica > backup_escola.sql

Restaurando o Banco de Dados:

# Importando o ficheiro .sql para uma nova base de dados
mysql -u root -p nova_escola < backup_escola.sql

Métricas Fundamentais: RPO e RTO

  • RPO (Recovery Point Objective): Determina a quantidade máxima de dados que a empresa aceita perder em tempo (ex.: se o backup roda a cada 24 horas, o RPO é de 24h de perda).
  • RTO (Recovery Time Objective): É o tempo máximo aceitável que a equipe leva para restaurar o sistema e colocá-lo no ar novamente após uma falha.

Atividade Prática

  1. Explique a diferença entre um **Backup Lógico** e um **Backup Físico**.
  2. Se você realizar um backup completo no domingo e backups incrementais de segunda a sexta, quais ficheiros precisará de utilizar para restaurar o sistema após um desastre na sexta à noite?
  3. Qual é a utilidade do utilitário mysqldump no dia a dia do administrador de banco de dados?

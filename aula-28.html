Semana 7 — Aula 4

Casos Práticos de Desenvolvimento com SQL

Projeto Integrado do 1º Bimestre

Nesta aula final, vamos consolidar todos os conhecimentos adquiridos ao longo do trimestre (Levantamento de Requisitos, Modelagem ER, Normalização até à 3NF e Implementação em SQL) através da construção prática de uma base de dados completa para uma Biblioteca Académica.

1. Script de Criação da Estrutura (DDL)

O script abaixo constrói as tabelas normalizadas com as suas devidas restrições de chave primária (PK) e estrangeira (FK):

CREATE DATABASE biblioteca_db;
USE biblioteca_db;

-- Tabela de Categorias
CREATE TABLE categoria (
    id_categoria INT AUTO_INCREMENT PRIMARY KEY,
    nome_categoria VARCHAR(50) NOT NULL UNIQUE
);

-- Tabela de Livros
CREATE TABLE livro (
    id_livro INT AUTO_INCREMENT PRIMARY KEY,
    titulo VARCHAR(150) NOT NULL,
    isbn VARCHAR(20) UNIQUE,
    ano_publicacao INT,
    id_categoria INT,
    CONSTRAINT fk_livro_categoria 
        FOREIGN KEY (id_categoria) REFERENCES categoria(id_categoria)
);

-- Tabela de Leitores
CREATE TABLE leitor (
    id_leitor INT AUTO_INCREMENT PRIMARY KEY,
    nome VARCHAR(100) NOT NULL,
    email VARCHAR(100) UNIQUE,
    data_cadastro DATE NOT NULL
);

-- Tabela Associativa de Empréstimos (N:M)
CREATE TABLE emprestimo (
    id_emprestimo INT AUTO_INCREMENT PRIMARY KEY,
    id_leitor INT NOT NULL,
    id_livro INT NOT NULL,
    data_emprestimo DATE NOT NULL,
    data_devolucao DATE,
    CONSTRAINT fk_emp_leitor FOREIGN KEY (id_leitor) REFERENCES leitor(id_leitor),
    CONSTRAINT fk_emp_livro FOREIGN KEY (id_livro) REFERENCES livro(id_livro)
);

3. Consulta de Relatório Consolidado (JOIN + WHERE)

Consulta que retorna os empréstimos pendentes (livros que ainda não foram devolvidos), juntando informações das 4 tabelas:

SELECT 
    l.nome AS leitor,
    b.titulo AS livro,
    c.nome_categoria AS categoria,
    e.data_emprestimo
FROM emprestimo e
INNER JOIN leitor l ON e.id_leitor = l.id_leitor
INNER JOIN livro b ON e.id_livro = b.id_livro
INNER JOIN categoria c ON b.id_categoria = c.id_categoria
WHERE e.data_devolucao IS NULL
ORDER BY e.data_emprestimo ASC;

Desafio Prático Final (Avaliação)

  1. Escreva um script SQL para criar uma View chamada vw_livros_mais_emprestados que exiba o título do livro e a quantidade total de vezes que ele foi emprestado.
  2. Crie um índice na coluna titulo da tabela livro para otimizar as buscas por nome do livro.
  3. Monte uma transação (TCL) que registre a devolução de um livro (atualizando data_devolucao na tabela emprestimo) e confirme as alterações de forma segura com COMMIT.
